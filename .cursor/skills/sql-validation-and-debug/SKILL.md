# SQL Validation and Debug

Use this skill when a feature depends on persisted data correctness.

## Typical tasks

1. Verify key tables and fields for a feature flow.
2. Run targeted read-only queries for debugging.
3. Compare expected data changes with actual records.
4. Provide concise query evidence in reports.

## Safety rules

- Prefer read-only queries for analysis.
- Avoid mutating production-like data unless explicitly required.
