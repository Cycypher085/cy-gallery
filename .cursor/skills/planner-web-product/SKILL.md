# Planner Web Product

## Apply this skill when

- A new feature is not clearly defined.
- UI style or interaction direction is being discussed.
- Planner needs to hand off executable tasks to coder/tester.

## Output checklist

1. Business goal and user value
2. In scope / Out of scope
3. Style and interaction guidance
4. Task breakdown with owner and dependencies
5. Acceptance criteria for each task
6. Test checklist and risk notes
